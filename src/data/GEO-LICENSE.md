# 基図データ（geo.json）の出典とライセンス

`tools/build_geo.py` が次のオープンデータから生成している。

| 内容 | 出典 | ライセンス・条件 |
|---|---|---|
| 市区町村の境界 | 国土交通省「国土数値情報（行政区域データ）」を、スマートニュース メディア研究所が加工・軽量化したもの（smartnews-smri/japan-topography） | 国土数値情報の利用規約に従う。出典の明記が必要 |
| 鉄道路線・駅 | station_database（Seo-4d696b75） | CC BY-SA 4.0（表示・継承）。**geo.json のうち `rail`・`stations` はこのライセンスを継承する** |

- アプリ内の「このアプリについて」に出典を表示している。表示は消さないこと。
- CC BY-SA の継承条件が運用上の支障になる場合は、鉄道データを国土数値情報（鉄道データ）に差し替えられる（`build_geo.py` の入力を替えるだけで、アプリ側の変更は不要）。
- 境界・路線とも表示用に簡略化している。位置の精度を要する用途には使えない。
