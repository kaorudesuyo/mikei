# 未景 MIKEI ── 首都圏の再開発を、時間で読む地図（v5.1）

> まだない街を、見に行く。

1枚の地図・1本の時間軸・4つの見かた。東京・神奈川・埼玉・千葉の再開発（オフィスまたは集合住宅を含むもの）を、
「いつ・どこに・誰が・誰と・どんな環境性能で」つくるのかという順で読めるようにした地図アプリ。

## 設計の考え方
| 利用シーン | 画面での答え |
|---|---|
| 再開発を俯瞰する | 立体の地図に、案件を「光の柱」で置く。高さ＝建物の高さ、太さ＝延床面積 |
| 時間とともに街と人口がどう変わるか | 下の時間軸を再生／ドラッグ。柱が着工から竣工へ伸び、地面の色（人口・2020年＝100）が滑らかに変わる |
| 施主の傾向 | 「施主」レンズ。柱が上位8社の色に変わり、勢力図になる。企業を選ぶと集中エリアと施工会社が分かる |
| 施工会社の傾向 | 「施工」レンズ。同じ操作で、エリア別と施主別の内訳が分かる |
| 環境認証 | 「環境認証」レンズ。取得済／予備認証／取得予定を塗り分け、制度ごとに一覧できる |

- 白＝竣工済、金＝これからの街（実線＝工事中、破線＝計画、点線の輪＝時期未定）。金はブランド既定どおり「未来」にだけ使う。
- 操作は「時間を動かす」「レンズを替える」「街を選ぶ」の3つに絞った。絞り込みはエリアの1軸だけ。

## 構成
```
index.html            エントリ（CSP の meta を含む）
src/
  data/db.json        ← Excel データベースから自動生成（手で編集しない）
  data/geo.json       ← 基図（境界・鉄道・駅）。オープンデータから自動生成
  data/index.js       表示用の索引・集計（状態判定、企業の順位、認証、人口の補間）
  store.js            画面の状態（時刻・レンズ・選択）
  map/MapStage.jsx    基図（MapLibre GL・外部タイルなし）とカメラ
  map/overlay.js      案件の柱・ラベル・当たり判定（2Dキャンバス）
  ui/Chrome.jsx       ロゴ、レンズ切替、検索、時間の操作（PC＝タイムライン／スマホ＝ダイヤル）、字幕、起動演出
  ui/touch.js         触覚フィードバックと、引き出すシートの挙動
  ui/Panels.jsx       左パネル（時間／施主・施工／環境認証）
  ui/Detail.jsx       案件の詳細ドロワー
  styles.css          デザイントークンと全スタイル
tools/
  build_data.py       Excel → db.json
  build_geo.py        オープンデータ → geo.json
  serve.mjs           本番同等ヘッダーの検証用サーバー
  pentest.mjs         自己ペネトレーションテスト
public/               アイコン、manifest、各ホスティング用のセキュリティ設定
```

## データの流れ（データベースが唯一の正）
```
mikei-redevelopment-database-v2.0.xlsx ──(python3 tools/build_data.py <xlsx>)──▶ src/data/db.json ──▶ アプリ
```
- アプリは db.json だけを読む。案件・エリア・認証・出典を直すときは **Excel を直して再生成**する。
- 変換時に足しているのは集計用の正規化だけ：
  - 施主の名寄せ（企業グループ：三井不動産＋三井不動産レジデンシャル など。定義は `build_data.py` の `GROUPS`）
  - 施工会社の抽出（「前田・大末JV」→ 前田建設工業・大末建設。未定・解体のみ・予定段階は数えない）
  - 時間軸の数値化（「2029年3月」→ 2029.21。竣工年・進捗と矛盾しないよう補正）
- 件数の数え方：共同事業は各社に1件ずつ。施工会社が未定の案件は施工の集計に含めない。

## 使い方
```bash
npm ci                 # 依存の導入（バージョン固定・インストール時スクリプト無効）
npm run dev            # http://127.0.0.1:5173
npm run build          # dist/ に静的ファイルを出力
npm run pentest        # 自己ペネトレーションテスト（要 Playwright）
python3 tools/build_data.py path/to/database.xlsx      # データ更新
```

## 公開
`dist/` をそのまま置けば動く（相対パスで出力しているのでサブディレクトリでも可）。
| 公開先 | セキュリティヘッダー | 備考 |
|---|---|---|
| Netlify | `dist/_headers` が自動で効く | 推奨。`netlify.toml` 同梱のため画面での設定は不要（下記） |
| Cloudflare Pages | `dist/_headers` が自動で効く | ビルドコマンド `npm run build`、出力先 `dist` |
| Vercel | `vercel.json` | 同上 |
| レンタルサーバー（Apache） | `dist/.htaccess` | PHP を実行させない設定を同梱。`SECURITY.md` の確認事項を参照 |
| GitHub Pages | ヘッダー不可（meta の CSP のみ） | クリックジャッキング対策が効かないため非推奨 |

## スマホでの体験（iPhone 16 以降を基準に設計）
| 場所 | 役割 |
|---|---|
| 下端のダイヤル | 目盛りを指で左右に送って時間を動かす。慣性つき。年をまたぐたびに小さな手応え（触覚）。目盛りをタップするとその年へ |
| その下のタブ | 4つの見かたの切替。親指の届く位置にまとめた |
| 引き出すシート | 畳むと1行の要約（竣工済・工事中・計画の件数、上位2社など）。引き上げると半分、さらに全面。地図を動かすと自動で畳む |
| 案件の詳細 | 柱をタップすると下から半分の高さで開く。引き上げて全面、引き下げて閉じる |
| 検索 | 全画面。何も打たなくても、案件の多いエリアと上位の施主が並ぶ |
| 再生 | ▶ で街が育つ。年ごとに最大の竣工案件が字幕で出て、竣工の瞬間に波紋が広がる。カメラがゆっくり回る |

- 文字入力は16px以上（iOS の自動拡大を防ぐ）、操作対象は44px以上。ノッチ・ホームバーの余白（safe-area）に対応。
- 「ホーム画面に追加」で、ブラウザの枠なしの全画面アプリとして開ける（アイコン・起動色を用意）。
- 描画の解像度は2倍までに抑え、操作がないときは描画を約12fpsに落として発熱と電池消費を抑える。

## GitHub ＋ Netlify で公開する手順
1. GitHub のリポジトリの**一番上の階層**に、`package.json`・`netlify.toml`・`index.html`・`src/` などが直接並ぶように置く。
   `mikei/` のようなフォルダの中に入れると、Netlify が `package.json` を見つけられずビルドに失敗する（エラー：`Could not read package.json`）。
2. Netlify で「Add new project → Import an existing project → GitHub」からリポジトリを選ぶ。
   ビルド設定は `netlify.toml` から自動で読み込まれる（Build command：`npm run build && rm -f dist/.htaccess`、Publish directory：`dist`）。
3. 以後は GitHub に変更を上げるたびに、自動でビルド・公開される。
- `node_modules/` と `dist/` はリポジトリに入れない（Netlify がその場で作る）。
- どうしてもフォルダの中に置く場合は、Netlify の Base directory にそのフォルダ名（例：`mikei`）を入れる。

## 対応環境
WebGL が使えるブラウザ（Chrome / Edge / Safari / Firefox の現行版、iOS・Android）。ピンチで拡大、2本指の上下で傾き、2本指の回転で向きを変えられる。
「視差効果を減らす」設定の端末では、起動演出と明滅を省く。

## 既知の制約
- 人口は各エリアを代表する市区の値（データベースの定義どおり）。全市区町村の推計は収録していない。
- 境界・鉄道は表示用に簡略化している。高倍率では実際の線形と数十メートルずれることがある。
- 案件の位置は町丁目レベルの概略。柱の高さ・太さは見やすさのために縮尺を誇張している。
- 2026年11月に追加収録した97件は、環境認証の情報がまだ少ない。
