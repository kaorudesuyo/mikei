# 未景 MIKEI ── 首都圏 再開発マップ 2020–2050

> まだない街を、見に行く。

首都圏の再開発を巨視し、街がどう変わっていくかを時系列で追うための地図。
東京・神奈川・埼玉・千葉の再開発案件、既存オフィスストック、環境認証、
人口動態（社人研 令和5年推計）を一枚で読む情報プラットフォーム。

## ブランド

- 名称：**未景（MIKEI）**／「未だ見ぬ景色」の意。地図に載るのは現在ではなく未来の街並み
- アイコン：`public/icon.svg`（96px以上）、`public/favicon.svg`（32px以下の簡略版）
- 金 `#E0B25C` は「未来・計画中」を指す色。アイコン内で他要素に流用しない
- 和文は明朝・字間.16em、欧文 MIKEI は字間.46emで和文の下に置く（単独使用不可）
- 起動時はアイコンが中央から迫るスプラッシュを表示（`Splash`／`prefers-reduced-motion`では省略）

## 技術構成

- React 18 + Vite 5（ビルド）／ recharts（グラフ）
- 地図は外部タイルに依存しない自前SVG投影（オフラインでも動作、APIキー不要）
- CSSはデザイントークン（CSS変数）ベースの1ファイル。UIフレームワーク非依存

## ディレクトリ構成（保守の考え方）

```
src/
├── data/                 # ★ データ層。更新作業は原則ここだけを触る
│   ├── projects.js       #   再開発案件（P）。1案件=1オブジェクト
│   ├── blocks.js         #   22ブロック定義・人口系列・ストック類型
│   ├── areaCerts.js      #   街区・エリア一括の環境認証（LEED ND等）
│   ├── certSystems.js    #   認証スキーム定義・ランク色・用途・進捗
│   ├── stock.js          #   東京23区ストック統計＋23区外の市況（REGIONAL）
│   ├── sources.js        #   出典マスタ（S）。全データはここのIDで出典を参照
│   └── geo.js            #   投影定数・海岸線・県境・鉄道のポリライン
├── lib/utils.js          # 純粋関数のみ（副作用なし・テスト容易）
├── components/
│   ├── MapView.jsx       # 地図（パン/ズーム/LOD/人口レイヤー）
│   ├── DetailDrawer.jsx  # 案件詳細ドロワー（PC=右／SP=ボトムシート）
│   ├── views.jsx         # 年表・ストック・環境認証・一覧
│   ├── panels.jsx        # ブロックカード・読み方パネル
│   ├── ui.jsx            # RankBadge等の共有部品
│   └── icons.jsx         # 線画SVGアイコン・認証シンボル（原図）
├── styles.css            # デザイントークン＋全スタイル
├── App.jsx               # 状態管理（フィルタ）とレイアウト
└── main.jsx
```

**設計方針**

1. **データとUIの完全分離** — 案件の追加・修正は `src/data/projects.js` の
   オブジェクト1つを編集するだけ。UIコードに触れる必要はない。
2. **出典の一元管理** — すべての出典URLは `sources.js` に集約し、各データは
   IDで参照する。リンク切れ対応が1箇所で済む。
3. **認証の二層モデル** — 棟単位の認証は各案件の `cert`、街区一括（LEED ND等）は
   `areaCerts.js` に分離。集計時の二重計上を構造的に防ぐ。
4. **純粋関数の分離** — `lib/utils.js` は React 非依存。単体テストを足す場合は
   ここから始められる。
5. **外部依存の最小化** — 地図タイル・地図SDK・UIフレームワークを使わない。
   依存は react / react-dom / recharts の3つのみで、サプライチェーンリスクと
   ビルドサイズを抑えている。

## 収録基準

オフィス（事務所）または集合住宅を用途に含む再開発のみを収録する。
商業単独・アリーナ単独・庁舎単独・交通インフラ単独の事業は対象外。
新規登録時は `mix` に事務所または住宅が含まれることを確認すること。

## データ更新の手引き

### 案件を追加する
`src/data/projects.js` に以下の形式で追記する。

```js
{id:"t2-08", n:"案件名", blk:"T2", ll:[経度,緯度],
 st:"plan",              // done=竣工済 / wip=工事中 / plan=計画
 y:2031, yl:"2031年度 竣工予定", s:"2027年 着工予定",
 fl:"地上45階／地下3階", h:220, gfa:180000, use:"mixed",
 mix:"事務所／商業／ホテル",
 devs:["◯◯不動産"], own:"…再開発組合（◯◯不動産が参画）",
 des:"—", con:"—",      // 未公表は "—"。推測で埋めない
 ft:"2〜3文の特徴。",
 cert:[{sys:"ZEB",scope:"事務所部分",rank:"ZEB Ready",stage:"取得予定",date:"—"}],
 tier:"C",               // A=一次資料確認 / B=専門メディア / C=構想段階
 src:[S.xxx]},
```

### 環境認証の記載ルール（重要）
- **棟単位**（LEED BD+C、CASBEE、ZEB…）→ 案件の `cert` へ
- **街区一括**（LEED ND、街区DBJ…）→ `areaCerts.js` へ。`members` に構成案件IDを列挙
- 同一認証の Plan認証 → 本認証 は `stages` 配列で1件にまとめる（2件と数えない）
- ZEB と BELS は同一評価枠組みの別表示。ZEB区分公表案件は ZEB として記載

### 定期更新が必要なデータ
| データ | 更新頻度 | 出典 |
|---|---|---|
| 23区ストック（stock.js） | 年1回（1月頃） | ザイマックス総研 オフィスピラミッド |
| 供給見通し | 年1回（4〜5月） | 森トラスト・森ビル 供給量調査 |
| 23区外市況（REGIONAL） | 月次〜四半期 | 三鬼商事（横浜）・CBRE（さいたま等） |
| 人口推計 | 約5年ごと | 社人研 地域別将来推計人口 |
| 竣工予定年 | 随時 | 各事業者リリース |

## セキュリティ

本アプリはバックエンド・外部API・アカウント・Cookieを一切持たない完全静的SPAで、
攻撃面を構造的に最小化している。その上で以下の防御層を実装済み。

**コード面（監査済み・すべて0件）**
- `dangerouslySetInnerHTML`／`eval`／`innerHTML` 不使用（XSSシンクなし）
- 外部通信ゼロ（`fetch`等なし。出典リンクは通常のナビゲーションのみ）
- 個人情報の保存なし（localStorage / sessionStorage / Cookie 不使用）
- 全外部リンクに `rel="noreferrer"`（noopener含意・タブナビング対策）

**配信面**
- CSP：`index.html` のmetaタグ（ヘッダー設定不可のホスティング向けの最終防御層）に加え、
  `public/_headers`（Netlify / Cloudflare Pages）と `vercel.json`（Vercel）で
  `frame-ancestors 'none'` を含む完全版を配信。自己ホスト以外のスクリプト実行・接続を全面遮断
- `X-Content-Type-Options: nosniff`、`Referrer-Policy`、`Permissions-Policy`（カメラ・マイク・
  位置情報等を明示的に無効化）、`COOP` / `CORP`、`HSTS` を同梱設定で付与
- ソースマップは本番ビルドに含めない（`vite.config.js`）

**サプライチェーン面**
- 依存は react / react-dom / recharts の3つのみに抑制し、バージョンを完全固定（`^`なし）
- `package-lock.json` を同梱。導入時は `npm ci` を使うこと（lockfileと完全一致で再現）
- `npm run audit` で本番依存の脆弱性チェック（現時点：0件）

**運用ルール**
- 依存更新は `npm audit` 確認とビルド・lint通過をセットで行う
- CSPを緩める変更（外部スクリプト追加等）はレビュー必須とする

## 既知の制約

- 地図は模式投影（正距円筒の近似）。測量精度は持たない
- 川崎・千葉市は主要仲介の定点調査対象外のため市況欄は「—」
- LEED・WELL・CASBEE等の公式ロゴは各機関の登録商標のため使用せず、
  独自シンボルで表示している。公式マークの掲出には各機関の許諾が必要
